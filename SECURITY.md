# Security

Report vulnerabilities privately through **Security → Report a vulnerability** in
this repository. The maintainer enables private vulnerability reporting before
the public launch. If the private reporting control is unavailable, do not put
sensitive details in a public issue.

Useful reports include unintended audio/text disclosure, credential exposure,
permission bypasses and execution of untrusted conversation content. Include a
minimal synthetic reproduction and affected revision, without real credentials,
private recordings or other people's data.

This is an early source alpha. Use accounts and tools you control, inspect their
permissions, and obtain agreement before recording a conversation. Model/provider
behavior and operating-system permissions remain separate boundaries.
